Desenvolvimento de um gerador de tabuadas em Python, criado para realizar cálculos matemáticos de forma automatizada a partir da operação e do número informados pelo usuário. A aplicação permite selecionar entre quatro operações matemáticas — adição, subtração, multiplicação e divisão — e, após a escolha, solicita um número para gerar uma sequência de cálculos utilizando valores de 1 a 100. Os resultados são apresentados diretamente no terminal, proporcionando uma interação simples e objetiva com o usuário.

Durante o desenvolvimento, foram aplicados conceitos fundamentais da linguagem Python, como entrada e saída de dados, conversão de tipos, estruturas condicionais (`if`, `elif` e `else`), estruturas de repetição (`for`), utilização da função `range()` e operadores matemáticos. Também foram utilizadas f-strings para a formatação e apresentação dos resultados de maneira organizada, além da formatação de números decimais nas operações de divisão.

O projeto foi desenvolvido com foco no fortalecimento da lógica de programação e na aplicação prática de conceitos básicos de Python, permitindo exercitar estruturas de decisão, repetição, operações matemáticas e interação com o usuário por meio do terminal. A construção da aplicação também contribuiu para o desenvolvimento da capacidade de transformar uma necessidade simples em uma solução automatizada e funcional.
